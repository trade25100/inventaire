🔌 Scanner USB LENVII 1D / 2D / QR

Branchez le scanner en USB, choisissez le mode USB Keyboard / USB-KBW et cliquez sur « Activer le scan ». Scannez ensuite un code. Le suffixe Entrée est recommandé, mais facultatif.

Correction appliquée uniquement aux codes ressemblant à des codes numériques. Désactivez-la pour les QR contenant du texte ou des caractères spéciaux.

Mode USB prêt à être activé.

Si un code est inconnu, le formulaire sera prérempli. Si le lecteur n'envoie pas Entrée, la détection automatique intervient après une courte pause.

🗺 Plan interactif de la chambre

Créez vos zones (armoire, bureau, lit…), puis cliquez dessus pour afficher les objets. Les emplacements déjà enregistrés sont repris automatiquement.

Pour associer un objet à une zone, commencez son emplacement par le nom de la zone : « Armoire > Étagère 2 ».
